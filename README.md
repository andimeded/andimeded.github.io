# Andi Mededovic | Engineering Portfolio

Personal portfolio for Andi Mededovic, Electrical & Electronics Engineering student at California State University, Sacramento (B.S. expected May 2027).

The site covers hardware, firmware, digital design, and silicon validation work aimed at the semiconductor industry, including:

- **STM32 Fire Detection System**: multi-sensor alarm in embedded C on an ARM Cortex-M4
- **FPGA Digital Design Labs**: Verilog state machines and display drivers on an Intel MAX 10
- **Autonomous Lifeguard Drone**: senior design team project (power system)

Built with plain HTML, CSS, and JavaScript, and hosted on GitHub Pages.

## Structure

```
index.html        page content
css/style.css     styles
js/script.js      menu, scroll effects, image viewer

```
